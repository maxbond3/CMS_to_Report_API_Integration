# Конвейер интеграции CMS и Report API

Автоматизированный конвейер синхронизации данных на базе **n8n**, **PostgreSQL** и **Python** для связи каталога запчастей (CMS) с сервером отчетности (Report API).

---

## 📁 Структура репозитория

* `compose.yml` — Конфигурация облегчённого Docker-стека (n8n, PostgreSQL и task runners без лишних AI-модулей).
* `db/` — Инициализация базы данных:
  * `01_create_spares_table.sql` — Создание таблицы `spares`.
  * `02_seed_spares_data.sh` — Автоматическая загрузка начальных данных из JSON при первом запуске.
  * `spares_seed_data.json` — Исходный набор запчастей.
* `n8n/` — Автоматическая настройка n8n:
  * `workflow.json` — Готовый воркфлоу интеграции.
  * `credentials.json` — Шаблоны учетных данных (подтягивают значения из переменных окружения).
* `.env_example` — Шаблон переменных окружения.
* `.gitignore` — Правила исключения локальных файлов и `.env` из Git.

---

## 🚀 Быстрый старт (запуск «из коробки»)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/maxbond3/CMS_to_Report_API_Integration.git
   cd CMS_to_Report_API_Integration
   ```

2. **Настройте переменные окружения:**
   ```bash
   cp .env_example .env
   ```
   Откройте файл `.env` и заполните параметры подключения к внешнему API (`API_URL`, `API_USERNAME`, `API_PASSWORD`). Параметры базы данных и сервисов n8n уже преднастроены.

3. **Запустите контейнеры:**
   ```bash
   docker compose up -d
   ```
   При первом запуске автоматически создастся таблица в PostgreSQL, загрузятся начальные данные из JSON, импортируются учетные данные и опубликуется воркфлоу.

4. **Откройте интерфейс n8n:**
   Перейдите по адресу [http://localhost:5678](http://localhost:5678) и создайте локальную учетную запись администратора.

## ⚙️ Архитектура конвейера

1. **[Manual / Schedule Trigger]** — Запуск по расписанию или вручную.
2. **[GET /cms/spares]** — Постраничный опрос API CMS до полной выгрузки данных.
3. **[DB: Upsert Spares]** — Сохранение записей в PostgreSQL с обновлением дубликатов (`ON CONFLICT (spare_code)`).
4. **[DB: Select Clean]** — Выборка полей в строгой последовательности.
5. **[Format: Matrix]** — Python-скрипт преобразует строки таблицы в CSV без заголовков с разделителем `;`.
6. **[POST /auth/login]** — Получение временного токена Bearer JWT.
7. **[POST /report/csv]** — Отправка готового CSV-потока в кодировке UTF-8 на сервер отчетов.
